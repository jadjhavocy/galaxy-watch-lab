Журнал решений

    02 — Профили

    Измени назначение жеста и нажми «Применить настройки», чтобы активировать личный профиль. Изменения сохраняются только в этом браузере.

    Пока это назначение команд осям гироскопа, не калиброванные движения вправо/влево. Режим DRY RUN не посылает медиаклавиш. В LIVE-режиме системные клавиши не гарантируют выбор определённого приложения.
    03 — Симулятор движений кисти

    Нажми «Активировать», затем один из жестов. Для следующей команды активируй управление заново. Симулятор формирует искусственные IMU-пакеты, которые проходят через исходный GestureEngine.

    Только localhost 127.0.0.1:8772 · без ADB и подключения часов · по умолчанию DRY RUN · системные медиаклавиши только после явного согласия.
